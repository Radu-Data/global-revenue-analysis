# Global Revenue Performance Dashboard

## Project Overview
This project leverages advanced Excel modeling to analyze historical sales data and identify potential revenue vulnerabilities, highlighting critical customer concentration risks and seasonal market trends.

## Tools Used
* **Microsoft Excel:** Pivot Tables, Power Pivot, and DAX measures.

## Key Insights
*	Built an Excel dashboard analyzing $1B+ in historical sales data to identify revenue concentration risks, seasonal sales declines, and customer dependency trends using Pivot Tables, Power Pivot and DAX measures.
*	Identified customer concentration risk (42% revenue dependency on single client) and a ~45% seasonal revenue decline following Q1 peaks.
